Do not assume the WordPress starter's 1 CPU/1 GB allocation is the team's available quota. Document resource requirements and how to adjust them without compromising application operation.

RepoRun prohibits Compose settings ports, env_file, labels, restart and networks. It also prohibits absolute host paths, Docker socket mounts and privileged containers. Do not put these in the RepoRun deployment Compose file. If local host-port mapping is needed, isolate it in an optional local-only override that RepoRun does not load.

Ingress is managed by stack.yml, not Compose host port mappings. The supplied minimal schema is:

  - name: app
    service: web
    port: 80
    primary: true
    access:
      type: public

The service name must match the actual Compose application service and port must match its internal listener. Public is a documented access type; use it for the presentation endpoint if permitted by course instructions. Other documented types are cas, team and basic_auth. Omitted access defaults to cas; authenticated is not a valid current access type. Do not bypass university access policies. Keep application member/admin authentication and authorization independent of endpoint access. Record any course-required access change and how reviewers will reach the site.

Use repository-relative persistent bind mounts under .stack-data/ for MariaDB data and uploaded images. Ensure directories and permissions are initialized appropriately. Keep mutable data out of the application image and out of Git. Do not rely on a normal source checkout path surviving reset/reclone. RepoRun preserves .stack-data/ on reset/reclone and preserves volumes when stopping; its Delete runtime data action destroys databases/uploads under .stack-data/. Document backup/restore and never use destructive runtime-data deletion as a routine deployment step.

Configure secrets through RepoRun stack-level environment values and Compose environment interpolation. Do not commit credentials, real .env files or database contents. Environment names must match ^[A-Z_][A-Z0-9_]{0,127}$. Required missing references fail validation; defaults such as ${LOG_LEVEL:-info} are supported. Use a separate least-privileged application database account. Do not print secrets in logs or documentation.

Initialization must not erase persistent data or duplicate demo records on redeploy. Document that database initialization variables/scripts generally affect an empty data directory and are not a substitute for updates to an existing database.

RepoRun Deploy/Redeploy fetches the configured branch, validates the repository and builds/starts services. Start/Wake uses the last trusted configuration without fetching Git or rebuilding. Idle stacks may sleep and wake on request; do not rely on a permanently running background scheduler for essential workflows. Document possible first-request startup delay.
